# Лабораторная работа № 2. Вариант 4

## Функции и стандартныху средства ввода-вывода в языке Си++

### Условие задачи
В работе создать массив (вектор) объектов структурного типа размерности n, необходимо сохранить его в файле в текстовом и двоичном режимах, обеспечить чтение данных из файла.  Сделать выводы о сравнительных размерах двух файлов с данными (текстовом и двоичном). Использовать в работе шаблон vector и класс string. Режимы приложения задаются как параметры командной строки, см. п. 3. Для чтения из файла и записи в файл структурной переменной использовать функции, или отдельные функции для текстового и двоичного режимов, или реализовать эти режимы в одной функции (функция для чтения и другая функция для записи), тогда выбор режима задать с помощью дополнительного параметра. 

**Вариант 4:** Структура «сотрудник» (поля: ФИО, дата приема на работу, должность, базовый оклад).
